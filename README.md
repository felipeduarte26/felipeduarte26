### 🚀 Sobre mim
 
Sou **Tech Lead Mobile** e **Arquiteto de Software**, com foco em construir aplicações móveis robustas, escaláveis e bem testadas. Meu dia-a-dia é resolver problemas de **integração nativa**, **performance** e **arquitetura modular** em apps de larga escala.
 
- 🏗️ Apaixonado por **Clean Architecture**, **SOLID** e **Clean Code** — aplico de verdade, não só na teoria
- 📱 Trabalho com arquitetura **SuperApp**: módulos Flutter integrados a um host React Native via bridge nativo (AAR / XCFramework)
- 🔐 Construindo um **SDK Android de verificação de identidade** — face liveness, anti-spoofing (MiniFASNet/LiteRT), face matching (FaceNet) e UI em Jetpack Compose
- 📊 Mantenedor de bibliotecas internas de **observabilidade** (Firebase + Sentry sob Facade/Strategy/Composite)
- 🤖 Criador do `danger-bot` — automação de code review para Flutter/Dart com plugins de performance, segurança e PR hygiene
- 🌱 Sempre estudando: Kotlin nativo, on-device ML, biometria e padrões de SuperApp
